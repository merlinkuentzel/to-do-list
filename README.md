<h3>To_Do_Liste:</h3>

Kleines Programm, die Aufgaben entgegen nimmt und in einer Liste speichert.

<h3>Aktueller Stand:</h3>

4-Funktionen:

1. Aufgabe hinzufügen
2. Aufgaben anzeigen
3. Aufgabe löschen
4. Programm beenden

Alle Funktionen lassen sich mit der dazugehörigen Zahl und Enter auswählen.

In der jeweiligen Funktion können beliebig viele Aufgaben hinzugefügt bzw. gelöscht und angezeigt werden.

Um eine Funktion zu verlassen und zum Hauptmenü zurückzukehren, muss "fertig" eingegeben werden.

Programm läuft solange, bis das Programm mit "4" beendet wird.

<h3>WICHTIG!!!</h3>
Liste wird aktuell noch nicht gespeichert und erlischt, sobald das Programm beendet wird.
